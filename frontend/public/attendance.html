Backup & recovery

Keep a secure copy of your records.

Weekly JSON backups are admin-only and include the selected attendance range, employee account hashes, client/site details and correction requests. To restore, stop the server, preserve a copy of the current data folder, then use the backup’s employees, attendance, sites, and correctionRequests arrays to rebuild the matching data/attendance-*.json files as JSON arrays. Keep the backup private; hashes are password-protected but still sensitive.
